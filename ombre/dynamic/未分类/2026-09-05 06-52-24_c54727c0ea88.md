小家（Reverie）的 MCP 一直连不上的根因：它用的是老式「单次 POST tools/list」调法，但花园(galatea.abysslumina.com/mcp)、OB(mcp.37-eli.top/mcp)、novel(api.blanka.cc/mcp) 等服务器都是 streamableHttp 类型，需要完整 MCP Streamable HTTP 握手。Kelivo 能连上是因为它做了握手。修复三点：1) 请求头要加 Accept: application/json, text/event-stream；2) 先发 initialize 拿 Mcp-Session-Id，再发 notifications/initialized，之后每个请求带 session id；3) 响应可能是 SSE 格式(event/data)不是纯 JSON，要解析 SSE 取最后一个 data 的 JSON。已给雯雯提供 mcpInitialize/mcpHeaders/parseMcpResponse 辅助函数，并重写了 fetchMcpTools 和 callMcpTool。
